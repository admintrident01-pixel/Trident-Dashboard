# Icons

Use the user-supplied Feather pack as the shared icon language. It contains 287 original SVGs in public/icons/feather, combined in public/icons/feather-sprite.svg for a single cacheable browser request. Preserve the original asset files and MIT attribution. Use src/Icon.jsx for React interfaces, with a supplied Feather name, existing control sizing and currentColor. Icons supplement clear visible button text or accessible labels. Keep the navigation compact; do not add decorative icons that crowd its names.

For a missing concept, draw a matching SVG: 24 × 24 viewBox, no fill, 2-unit currentColor strokes, rounded caps and joins, simple geometry. Add it to public/icons/custom-sprite.svg and reference it as custom-NAME. Do not substitute emoji, bitmap art, filled icons or a second icon family. The custom unlink symbol is the first example. Existing workflow connector diagrams are diagrams and retain their tailored geometry.

Standard sizes: 12–14px in compact controls, 13px schedule locks, 15px schedule edge links, 16–20px standard controls, and 29px Home module cards. File icons scale with the existing small/medium/large view choices. Preserve the schedule link orientation, placement and hover behaviour.
