TRIDENT PASSWORD LOGIN UPDATE

This update contains code only. Existing online data stays in BigQuery and PDF
storage. Do not repeat setup-cloud.sh or import the old data snapshot.

First login: click First login / Forgot password, confirm your work email,
then choose a password (12 to 128 characters). Each person chooses their own.
Future logins: work email + password. Recovery uses a fresh email link.
Password reset revokes other sessions. Passwords use salted scrypt hashes;
plain passwords are never saved. Disabled users cannot sign in.
Refresh keeps the current session. Normal sessions last 8 hours. Optional
Keep me signed in lasts 30 days. Sign out clears the stored session.
