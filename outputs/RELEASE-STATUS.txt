RELEASE
- Branch: main
- Release commit: eb75a58a6fbee39ed5ba7ba16a48481c5091f2de
- Base commit: cfcaa82e11d70fa5a0ff19b21bb2370fa5846fc6
- Push: cfcaa82..eb75a58 main -> main.
- Unpaid approved leave now contributes 0 payable hours while remaining visible in
  timesheets and reports. Payability is derived from the leave type, so stale saved
  paid flags cannot make unpaid leave payable again.
- New submitted timesheets store payableTotal; legacy records continue to derive a
  compatible payable total.
- Stocktakes now exclude stock that is Allocated or With client. Physical stocktake
  statuses are Available, Incoming, Refurbishing, Awaiting new asset number and Repair.
- onHandQuantity is deliberately unchanged because allocated stock remains business
  inventory; only the physical count quantities exclude it.
- Existing stocktake drafts created before this rule are marked draftOutdated, cannot
  be modified or completed, and prompt for a fresh count.
- Excel and PDF stocktake exports explain the client-stock exclusion.
