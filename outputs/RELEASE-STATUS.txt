WHAT CHANGED
- Added Edit / delete beside Add product, with a searchable catalogue manager and row-level Edit/Delete actions.
- Product code and description edits preserve product IDs, linked assets and history.
- Catalogue deletion requires a reason and is blocked when numbered stock, receipts or an open stocktake reference the product.
- Added a Retired stock section with individual Delete, Select, Select all, Clear selection and bulk deletion.
- Retired deletion uses revision checks, removes receipt references atomically and retains an audit snapshot / movement record.
- Stocktakes count only physically onsite stock: Available, Incoming, Refurbishing, Awaiting new asset number and Repair.
- Allocated, delivered (With client) and Retired stock are never included in stocktake counts.
- Retired deletion does not invalidate an open count, while catalogue additions and edits require a fresh count for an open draft.
- The previous unpaid-leave payable fix remains unchanged.
